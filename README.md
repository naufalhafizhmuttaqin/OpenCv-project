# OpenCV Projects

A collection of computer vision projects developed using Python and OpenCV. This repository showcases practical implementations of image processing, facial analysis, hand tracking, gesture recognition, and real-time detection.

## Projects

| Project | Description |
|---|---|
| **Eye Blink Detection & Drowsiness Detection** | Detects eye blinks and monitors potential signs of drowsiness using facial landmarks. |
| **Facial Emotion Detection** | Analyzes facial expressions to identify emotions using computer vision techniques. |
| **Finger Counter** | Detects hand landmarks and counts raised fingers in real time using a webcam. |
| **Gender & Age Detection** | Estimates age and gender presentation from facial images using computer vision models. |
| **Hand Gesture Detection** | Recognizes hand gestures by analyzing hand landmarks and finger positions. |
| **Sign Language Recognition** | Explores sign language recognition through hand gesture analysis. |

## Technologies

- **Python** — Core programming language
- **OpenCV** — Image processing and computer vision
- **MediaPipe** — Hand and facial landmark detection
- **NumPy** — Numerical computing and array operations

Additional libraries and pre-trained models may be required depending on the project.

## Getting Started

### Prerequisites

- Python 3.x
- Git
- A webcam for projects that use real-time video input

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/naufalhafizhmuttaqin/OpenCv-project.git
   ```

2. Navigate to the repository:

   ```bash
   cd OpenCv-project
   ```

3. Open the directory of the project you want to run.

4. Install the dependencies required by that project. For example:

   ```bash
   pip install opencv-python mediapipe numpy
   ```

5. Run the appropriate Python script from its project directory:

   ```bash
   python fingercounter.py
   ```

**Note:** Dependencies, model files, and execution steps may vary between projects. Refer to each project's files for specific requirements.
